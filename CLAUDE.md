# Assignment Tracker

A small Technify training project. Users will track school assignments.

## Planned feature
Add assignments with:
- Course
- Assignment name
- Due date
- Status

## Stack
- Frontend: Next.js (App Router, TypeScript, Tailwind CSS)
- Database: Supabase (**not added yet**)
- Deployment: Vercel

## Principles
- Keep the project intentionally small and polished.
- No extra features or dependencies beyond what is asked.
- Do not add Supabase until explicitly requested.
- Do not commit unless asked.

## Commands
- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — lint
